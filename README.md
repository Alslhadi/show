# عرض اللقاء التشاوري — تشغيل على استضافتك

## الملفات
- `public/index.html` — العرض كامل (الخطوط والصور والصوت داخله).
- `server.js` — خادم صغير يعرض الصفحة ويربط الجوال بالشاشة.
- `package.json` — يحتاج حزمة واحدة: `ws`.

## الرفع على Render (أو أي استضافة Node)
1. ارفع المجلد على GitHub.
2. في Render: New → Web Service → اختر المستودع.
3. Build Command: `npm install` — Start Command: `npm start`.
4. في Environment أضف: `CONTROL_PIN` = الرمز اللي تبيه (الافتراضي 2311).

## الاستخدام
- الشاشة: افتح الرابط على اللابتوب واضغط «عرض».
- الجوال: افتح نفس الرابط واضغط «تحكم من الجوال» وأدخل الرمز.
- أو افتح مباشرة: `الرابط/#control`

## تشغيل محلي للتجربة
npm install && npm start  →  http://localhost:3000
