# مركز التداول الذكي — النسخة 0.1

## التشغيل خلال 3 دقائق (وضع المحاكاة)
1. ثبّت Python 3.11 أو أحدث (ويندوز: فعّل خيار Add to PATH).
2. فك الضغط عن المجلد.
3. ويندوز: دبل كلك على `start_windows.bat` — ماك: `bash start.sh`.
4. افتح `.env` وغيّر `DASHBOARD_TOKEN` لكلمة سر قوية، ثم أعد التشغيل.
5. افتح المتصفح على `http://localhost:8000` وادخل بكلمة السر.

## مكونات النظام
| الملف | الوظيفة |
|---|---|
| `app/smc.py` | كشف القمم والقيعان، BOS، CHoCH، FVG، Order Blocks، السيولة، السويب |
| `app/indicators.py` | EMA، RSI، ATR، ADX، MACD |
| `app/decision.py` | بوابات الرفض + الدرجة من 100 + مستويات الدخول والأهداف |
| `app/risk.py` | حساب اللوت من مواصفات العقد، الحدود، زر الطوارئ |
| `app/engine.py` | الحلقة: تحليل كل شمعة M1 مغلقة، التنفيذ، إدارة الصفقات |
| `app/brokers/paper.py` | محاكاة (أسعار مولّدة — للتجربة فقط) |
| `app/brokers/mt5_broker.py` | ربط MetaTrader 5 (ويندوز) |
| `app/brokers/exness_api.py` | توقيع Exness API + قراءة الحساب (التنفيذ بانتظار الوثائق) |
| `app/static/index.html` | لوحة التحكم العربية |

## إدارة الصفقة
- الدخول: عند درجة 65+ واجتياز كل البوابات (الوضع الآلي).
- الوقف: خلف آخر قاع/قمة على M5 + 0.2 ATR.
- TP1 = 1R: إغلاق 50% ونقل الوقف للدخول.
- بعدها: وقف متحرك بمسافة 1 ATR.
- إغلاق إجباري بعد 4 ساعات، وقبل نهاية الأسبوع (عدا BTC).

## الأمان
- لا تشارك ملف `.env` ولا المفاتيح مع أي أحد.
- الحساب الحقيقي مقفل حتى `LIVE_TRADING_ENABLED=true` + عبارة تأكيد من اللوحة.
- النظام لا يرفع المخاطرة أبداً لتعويض خسارة.
